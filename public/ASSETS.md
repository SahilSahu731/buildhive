# Interface assets

- Inter is bundled locally under the SIL Open Font License. See `fonts/OFL-Inter.txt`.
- Demo portraits are placeholder images from [Pravatar](https://pravatar.cc/). Sample profiles and projects illustrate the interface; they are not live members or launches.
- Interface icons use the Phosphor and Simple Icons collections through React Icons.

- `artwork/auth-sculpture.webp` is original artwork generated with the built-in imagegen tool. Its prompt and implementation notes are recorded in [docs/design/auth-background.md](../docs/design/auth-background.md).
